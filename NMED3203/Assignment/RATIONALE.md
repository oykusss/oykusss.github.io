# Running Out — Design rationale

## Idea
Running Out asks the participant to fill a canvas with shapes. Pressing and holding grows a shape; releasing stamps it permanently. Every mark claims the round space around it and spends ink from one shared pot. The piece asks one question: do you make a few bold marks or many small ones, knowing that each choice decides what you can still do?

## Agency × Possibility
Agency lives in the hold-to-grow gesture: the participant chooses where a mark goes, how big it becomes and which shape it takes. Possibility lives in two limits, claimed space and ink. The premises depend on each other because these limits are produced by the participant's own earlier actions: a large circle placed early becomes a wall that stops the next shape from growing. Acting spends possibility, and the shrinking space of possibility makes each next action more deliberate. Free mode removes only the space rule, so comparing the two modes shows what Possibility adds.

## Theory
Wardrip-Fruin et al. (2009) separate triggering an event from agency, which needs an intention that the system visibly answers. A tap-to-stamp tool would only trigger, so I made size something the participant holds and decides, with the ink cost shown before release. Their account, however, treats agency as intentions being satisfied; my piece deliberately blocks intentions, and the paper says little about frustration as the experience itself.

Gaver (1991) describes affordances as relations between a person and an environment that can be perceptible, hidden or false. Without the dashed circles, claimed space would look free, a false affordance, so I drew every claim and an "×" cursor on blocked spots. Hold-to-grow, though, remains a hidden affordance carried only by the instruction line.

## What I learned
My first version gave each tool six stamps and shrank each mark as the tool ran out. Testing it, I noticed that every session ended the same way: twenty-four stamps, whatever I chose. My actions spent possibilities but never decided which ones disappeared. I replaced the counters with claimed space and shared ink, so earlier choices now shape later ones.
